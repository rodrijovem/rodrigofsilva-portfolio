# Rodrigo Silva - Portfolio

Professional portfolio showcasing product design cases, complex systems management, and business impact.

## 🚀 Stack

- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Phosphor Icons](https://phosphoricons.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Languages:** Internationalization (PT-BR / EN)

## 🛠️ Local Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

## 📦 Deployment

The project is configured for deployment on **GitHub Pages**.

1. Run `npm run build` to generate the `dist` folder.
2. Ensure `vite.config.ts` has the correct `base` path (currently set to `/rodrigofsilva-portfolio/`).
3. Push the `dist` content to the `gh-pages` branch or configure GitHub Actions for automatic deployment.
